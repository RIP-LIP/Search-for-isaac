数据来源
道具 / 饰品 / 卡牌 / 胶囊（ID、官方中文名、英文名、品质、图标）均由构建脚本 build.py 从本机已安装的《以撒的结合：忏悔 / 忏悔+》解包资源中提取， 未抓取任何第三方站点。 具体文件：stringtable.sta（官方简体中文本地化）、 items.xml、items_metadata.xml、pocketitems.xml、gfx/items/。
掉落物的例外
掉落物（红心、硬币、钥匙、宝箱、电池…）无法从本机解包资源反推，已实测确认： stringtable.sta 只有 THE_BATTERY_NAME 一类的关联道具名，没有按子类型分的掉落物名； entities2.xml 里没有 pickup 变体表。 这部分按 Project:译名表/实体 的「5 掉落物」段逐条固化在 build.py 的 PICKUPS 表里， 并已按该页原文校对（其中 5.100 / 5.300 / 5.350 三个泛用条目由道具、卡牌、饰品的「实体」按钮覆盖，故未重复列出）。

指令速记

  • 游戏外先把 options.ini 里的 EnableDebugConsole 改成 1；游戏内按 ` 打开控制台。
  • 道具 giveitem c1；饰品 giveitem t35；卡牌 / 符文 giveitem k31；胶囊 giveitem p0。
  • 卡牌和胶囊只能用 [类型][ID] 形式，不能输英文名。
  • 大胶囊用大写 P：giveitem P0，且 P 不能写成小写。
  • 实体按钮是在房间里生成一件掉落物（spawn），道具按钮是直接给角色（giveitem）。
  • 掉落物（红心、硬币、钥匙、炸弹、箱子、电池…）只能 spawn 5.xx.y 在地上生成，没有 giveitem / remove，所以该分类只有一个按钮。
  • 5.70.x 是胶囊的纹理编号，不是效果编号：游戏开局时才随机决定每种纹理对应哪个胶囊效果，所以 spawn 5.70.1 拿到的效果是随机的。要指定效果请用「胶囊 P」的 giveitem p0。
  • 剖腹产（C Section）只能写 g c678 或 g C section，写 c section 会被「道具」吃掉。
  • 命令对大小写敏感；remove * 清空角色全部道具与饰品。
